# سيرفر «لم المتراكم»

Node.js بدون إطار عمل ثقيل، المكتبة الوحيدة `pg` للاتصال بـ PostgreSQL.

## تشغيل محلي (بدون قاعدة بيانات، للتجربة بس)
```
node src/server.js      # بيشتغل على :3000 والبيانات في الذاكرة وبتتمسح مع كل إعادة تشغيل
npm test                # كل الاختبارات
```

## تشغيل بقاعدة بيانات حقيقية (Neon)
1. اعمل مشروع على Neon وانسخ رابط الاتصال (connection string).
2. في **SQL Editor** بتاع Neon: الصق محتوى `db/schema.sql` ونفّذه **مرة واحدة** (مش بيتكرر).
3. على جهازك: `npm install`، وحط الرابط في متغير بيئة `DATABASE_URL` (شوف `.env.example`).
4. `npm run seed` — بيدخل المنهج الرسمي من `app/shared/curriculum.json` (16 مادة، 46 وحدة، 143 درس، بأرقام الصفحات). تقدر تشغّله أكتر من مرة، ومش بيلمس الدروس اللي الطالب أضافها.
   - `db/seed.sql` نسخة يدوية للمواد الأساسية بس، من غير دروس، لو مش قادر تشغّل الـ Node seeder.
5. `npm start`
6. **اختبار قاعدة البيانات الحقيقية:** اعمل قاعدة تجريبية منفصلة (مش بتاعة الناس) ونفّذ عليها `schema.sql`، وبعدين:
   `TEST_DATABASE_URL=... npm test`
   ده بيشغّل نفس اختبارات الذاكرة على PostgreSQL، وبيمسح اللي أنشأه بعد ما يخلص.

## المنهج
- المصدر الوحيد للبيانات هو `app/shared/curriculum.json`، والعناوين وأرقام الصفحات منقولة من فهرس كتب الوزارة.
- الوقت التقديري لكل درس بيتحسب من فرق صفحاته (بين 30 و180 دقيقة)، وتقدر تعدّله من «المتراكم».
- اللغات التانية اختيارية: بتظهر بس لما الطالب يختار لغته في الملف الشخصي أو خطوة البداية.
- كتاب الأحياء لسه ما وصلش، فمادة `biology_science` ظاهرة بملاحظة وبدون دروس. مفيش دروس مخترعة.

## الأمان اللي اتعمل
- كلمات السر بـ scrypt بملح عشوائي، ولا بتتخزن ولا بتتعرض.
- جلسات بتوكن عشوائي (Bearer)، والمخزن في القاعدة **هاش** التوكن بس، وبتنتهي بعد 30 يوم، وتسجيل الخروج بيلغيها.
- رد واحد ووقت متقارب لـ«إيميل غلط» و«كلمة سر غلط».
- حد للمحاولات (8 دخول فاشل كل 15 دقيقة، و5 حسابات جديدة كل ساعة من نفس العنوان).
- فحص كل المدخلات، وحد لحجم الطلب، والصورة بحد 200 كيلوبايت ومتحقق من محتواها مش بس امتدادها.
- كل استعلام SQL بمتغيرات (parameterized).
- CORS في الإنتاج بقائمة مواقع مسموحة بس (`ALLOWED_ORIGINS`).

## حدود لازم تعرفها
- حد المحاولات **بيتخزن في ذاكرة السيرفر**: بيتصفّر مع إعادة التشغيل، ومش بيتشارك لو شغّلنا أكتر من نسخة.
- التوكن بيتخزن في المتصفح (مش كوكي)، فأي ثغرة XSS في الواجهة ممكن تسرقه. هنبني الواجهة بحذر لده.
- مفيش استرجاع كلمة السر لسه (محتاج إرسال إيميل).
- مفيش تأكيد إيميل لسه.
- `pgStore` اتكتب واتراجع لكن **ما اتجرّبش على PostgreSQL حقيقي في بيئتي**، فالخطوة 5 فوق مهمة.

## الـ API (كلها JSON، والمحمي محتاج `Authorization: Bearer <token>`)
| الطريقة | المسار | الوظيفة |
|---|---|---|
| GET | /api/health | فحص الحياة |
| POST | /api/auth/register · /api/auth/login · /api/auth/logout | الحسابات |
| GET | /api/me | بياناتي |
| PUT | /api/profile | الاسم والشعبة وتاريخ الامتحان واللغة التانية (`secondLanguage`: `lang2_french` · `lang2_german` · `lang2_spanish` · `lang2_italian` أو `null`) |
| PUT/GET | /api/profile/avatar | الصورة (PNG/JPEG/WEBP حتى 200KB) |
| GET/PUT | /api/availability | وقتي لكل يوم وأيام استثنائية |
| GET | /api/subjects · PUT /api/subjects/:id | المواد، ومستوى ضعفي وتاريخ امتحانها |
| GET/POST | /api/lessons | الدروس، وإضافة درس بتاعي |
| PATCH/DELETE | /api/lessons/:id | الحالة والوقت المقدّر، وحذف درسي |
| POST | /api/study-sessions · GET /api/stats | تسجيل المذاكرة وإجمالياتها |
| GET | /api/plan | **خطة الإنقاذ** |
