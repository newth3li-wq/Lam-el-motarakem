# واجهة «لم المتراكم» (React + Vite)
## تشغيل محلي
1. شغّل السيرفر (من فولدر السيرفر): `npm start` (على المنفذ 3000)
2. في فولدر الواجهة: `npm install` ثم `npm run dev`، وافتح الرابط اللي هيظهر (غالبًا http://localhost:5173)
## متغيرات
- `VITE_API_URL`: عنوان السيرفر (الافتراضي http://localhost:3000)
## ملاحظات
- التوكن بيتخزن في localStorage، فلازم نمنع أي ثغرة XSS (مفيش HTML خام في الكود).
- `public/_redirects` بيخلّي Cloudflare Pages يفتح أي مسار على الصفحة الرئيسية للتطبيق.
