# أدبي | منصة مذاكرتك — نسخة أولية

## التشغيل
1. فك ضغط ملف ZIP.
2. افتح `index.html` في Chrome أو Edge.
3. استخدم الموقع مباشرة. لا يحتاج تثبيت أو سيرفر.

## الموجود حاليًا
- واجهة عربية RTL متجاوبة مع الكمبيوتر والموبايل.
- لوحة رئيسية وإحصائيات.
- المواد الخمس: الإحصاء، التاريخ، الإنجليزي، الجغرافيا، العربي.
- إضافة الدروس يدويًا وتغيير حالة كل درس.
- حفظ البيانات تلقائيًا في LocalStorage على نفس المتصفح والجهاز.
- جدول حصص أسبوعي قابل لتعديل الوقت.
- اقتراح خطة بناءً على الدروس غير المكتملة وساعات المذاكرة.
- صفحة للمتراكم، تقدم المواد، مؤقت تركيز، واختبار توضيحي.

## ملاحظة مهمة عن المنهج
هذه نسخة تأسيسية وليست بعدُ مكتبة المنهج الرسمية الكاملة. لم أختلق أسماء وحدات أو دروس. لإضافة المنهج بدقة، زوّدني بفهرس أو PDF كتب الوزارة للعام الدراسي المقصود، وسنحوّل كل وحدة ودرس إلى محتوى وملخص وأسئلة موثقة.

## ملاحظات تقنية
- HTML + CSS + JavaScript عادي (بدون إطار عمل).
- البيانات محفوظة محليًا في المتصفح؛ لن تنتقل تلقائيًا بين الأجهزة.
- لا يوجد حساب مستخدم أو قاعدة بيانات أو رفع ملفات في هذه النسخة.
- الخط يُحمّل من Google Fonts عند توفر الإنترنت، ويعمل الموقع بخط بديل عند عدم توفره.

## تحديث هذه النسخة
- اختيار الشعبة عند أول تشغيل: أدبي / علمي علوم / علمي رياضة.
- حفظ اختيار الشعبة والاسم الاختياري محليًا على نفس المتصفح.
- زر تبديل بين الثيم الفاتح والداكن مع حفظ الاختيار.
- لوحة الألوان الجديدة: أخضر غابي هادئ + عاجي/ورقي + لمسات sage وذهبي دافئ؛ الوضع الداكن أخضر فحمي.
- ملاحظة: اختيار الشعبتين العلميتين مضاف كواجهة اختيار فقط في هذه المرحلة؛ محتوى المنهج المعروض ما زال خاصًا بأدبي، ولم تتم إضافة مناهج علمي بعد.

## تحديث المرحلة الثانية — Ocean Teal
- شريط بحث عام عن أسماء المواد والدروس والوحدات المضافة، مع نتائج مباشرة.
- فتح تفاصيل أي درس من بطاقة المادة، وتغيير حالته وحفظ التقدم.
- بطاقات المواد تعرض نسبة الإنجاز وشريط تقدم واضحًا.
- زر سريع لإضافة درس مباشرة إلى المادة المختارة.
- تحسين عرض اسم الطالب في الترحيب بالصفحة الرئيسية.
- تحسينات تفاعلية للبطاقات والتنقل، مع مراعاة الشاشات الصغيرة والوضع الداكن.
- هذه التحسينات تخص تجربة الاستخدام في الواجهة الحالية فقط؛ الحسابات وقاعدة البيانات والمزامنة بين الأجهزة ستأتي في مرحلة البنية الخلفية لاحقًا.


## تحديث المرحلة الثانية — إصلاح الحركة والتناسق
- تحسين إخفاء وإظهار القائمة الجانبية بحركة انسيابية باستخدام تحويلات GPU.
- تمدد مساحة المحتوى عند إخفاء القائمة، مع تمركزها أفقيًا بدل ترك فراغ جانبي.
- توحيد عرض المحتوى وتمركزه عند الشاشات العريضة ومستويات Zoom المختلفة.
- تحسين قواعد الشاشات المتوسطة والصغيرة ومنع التمرير الأفقي غير المقصود.
- احترام إعداد تقليل الحركة في نظام التشغيل.

## تحديث المرحلة الثانية — Espresso Bronze / UX refinement
- اعتماد نظام ألوان Espresso Bronze في الوضعين الفاتح والداكن مع أسطح متدرجة دافئة وتباين أوضح.
- توحيد ألوان المكونات والحالات التفاعلية والتركيز بلوحة المفاتيح، بدل الاعتماد على ألوان متفرقة من الثيمات السابقة.
- إصلاح إغلاق القائمة الجانبية على الموبايل عند الانتقال بين الصفحات، وإعادة ضبط حالة زر القائمة والـ backdrop.
- تحسين ظهور العناصر عند التمرير في الاتجاهين مع stagger خفيف، وإلغاء الحركة بشكل صحيح عند تفعيل تقليل الحركة.
- تقوية قواعد التخطيط للشاشات المتوسطة والصغيرة وتقليل احتمالات الـ overflow.
- الحفاظ على HTML/CSS/JS الحالي والبيانات المحلية والوظائف الموجودة دون إعادة بناء المشروع.
- تم فحص JavaScript syntax وHTML parsing وتوازن أقواس CSS وتحليل CSS الأساسي؛ لم يتم إجراء اختبار بصري شامل على أجهزة فعلية أو قياس FPS.


## تحديث 2.7 — لم المتراكم + Motion Boost
- تغيير اسم المنصة الظاهر في العنوان والهوية إلى «لم المتراكم».
- تقوية انتقالات الصفحات بحركة دخول سينمائية أعمق وخروج أسرع، مع blur وscale خفيفين.
- تحسين stagger للعناوين والأقسام والبطاقات، مع micro-interactions للأزرار والكروت.
- إضافة حركة تنفس هادئة للرسمة التوضيحية في الصفحة الرئيسية.
- احترام إعداد تقليل الحركة في النظام.
- لوحة Espresso Bronze ما زالت مؤقتة لحين اختيار لوحة الألوان الجديدة.

## تحديث الهوية البصرية — Pure Black + Silver
- Dark Mode بخلفية سوداء صريحة `#000000`، مع أسطح سوداء مرتفعة وحدود رمادية هادئة.
- Light Mode بخلفية رمادي فاتح `#F5F5F5` وبطاقات بيضاء.
- الفضي `#B9BEC6` هو لون التمييز الأساسي، مع إزالة التنافس بين الألوان القديمة.
- تم الإبقاء على نظام الحركة الحالي ودعم `prefers-reduced-motion`.
- لم يتم تغيير بنية البيانات أو حذف وظائف النسخة 2.7.


## تحديث 3.1 — القائمة والتحفيز والبروفايل
- القائمة الجانبية رجعت بحجمها الأصلي، وتظهر وتختفي من الزر أعلى اليمين فقط؛ تنزلق بحركة ناعمة والمحتوى يتمدد معها بنفس المدة والمنحنى، والزر يفضل ظاهرًا دائمًا.
- أنيميشن السكرول: العناصر تدخل من تحت عند النزول ومن فوق عند الصعود (بدون مستمع scroll، بـ IntersectionObserver).
- صفحة «ملفي الشخصي»: الاسم والشعبة والمستوى والنقاط والأيام المتتالية والأوسمة ونسخة احتياطية/استرجاع للبيانات.
- بطاقة تحفيز في الرئيسية: مستوى ونقاط وسلسلة أيام وعبارة يومية.
- تبديل الثيم بدائرة، وإصلاح اليوم والمؤقت ووميض الدارك (من 3.0).
- الحسابات الأونلاين (تسجيل/دخول/مزامنة) لم تُنفَّذ بعد: تحتاج مشروع Supabase.
- لم يتم اختبار بصري أو قياس FPS؛ طبقات CSS القديمة ما زالت موجودة.

## تحديث 3.2 — تقليل الحركة
- عند تفعيل «تقليل الحركة» في نظام الجهاز يعرض الموقع fade خفيفًا بدل إلغاء الحركة تمامًا.
- يظهر زر/مفتاح «حركة كاملة» (في الشريط العلوي وصفحة ملفي الشخصي) لمن جهازه مفعّل عليه تقليل الحركة فقط، واختياره يُحفظ.

## تحديث 3.3
- إصلاح الشاشة السوداء عند التنقل السريع بين الصفحات: حركة الخروج كانت تترك الصفحة شفافة، الآن تُلغى بعد انتهائها، والانتقال السريع يتخطى حركة الخروج، مع شبكة أمان تُظهر العناصر الظاهرة على الشاشة.

## تحديث 3.4
- الوضع الداكن هو الافتراضي (مفتاح حفظ جديد حتى يبدأ الجميع بالداكن).
- إعادة تصميم الوضع الفاتح: قائمة جانبية فاتحة بعنصر نشط داكن، أسطح بيضاء بحدود وظلال ناعمة، نصوص وأزرار بتباين أعلى، وأشرطة تقدم أوضح.
