# لم المتراكم

منصة مذاكرة عربية لطلاب الثانوية العامة، عملتها عشان الطالب ينظم مذاكرته ويلمّ المتراكم عليه خطوة بخطوة.

## التشغيل
فك الضغط وافتح `index.html` في Chrome أو Edge. مفيش تثبيت ولا سيرفر.

## فيها إيه
- الشعب التلاتة: أدبي، علمي علوم، علمي رياضة.
- مواد ودروس وتتبع لحالة كل درس.
- مخطط مذاكرة وجدول أسبوعي.
- إنقاذ المتراكم، واختبارات، وصفحة تقدمي.
- مؤقت تركيز.
- مستوى ونقاط وأيام متتالية وأوسمة.
- صفحة ملفي الشخصي ونسخة احتياطية للبيانات.
- وضع داكن (الافتراضي) وفاتح، وحركة ناعمة مع خيار تقليل الحركة.

## لازم تعرف
- بياناتك محفوظة على نفس المتصفح بس، فخد نسخة احتياطية من صفحة ملفي الشخصي.
- المنهج لسه مش مضاف، والاختبار الموجود تجريبي.
- تسجيل الدخول والمزامنة بين الأجهزة جاية في الخطوة الجاية.
